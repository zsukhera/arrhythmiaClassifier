1. 1D-CNN — Farag 2023 replication (HasanML/paper3/)
---------------------------------------------------
Code committed (13 Nov):
  - paper3 + paper4 source, tests, Colab notebooks
  - run scripts 1DCNN/run_paper3.sh and run_paper4.sh, how-to-run guides

Bugs found and fixed:
  - run_experiment.py: DS1 was undefined in the template fallback.
    It now uses DS1_TRAIN + DS1_VAL.
  - run_experiment.py: the --class-weight flag was ignored for P1.
  - train.py: EarlyStopping monitored the unweighted val_loss, which
    stopped training around epoch 27, before the S class was learned.
    Added a MacroF1Callback and now stop on val_macro_f1.
  - train.py: callback ordering. MacroF1Callback must come before
    EarlyStopping, otherwise the metric is missing from the logs and
    early stopping never triggers.
  - requirements.txt: added pytest; tensorflow>=2.22 for Python 3.14.

P1 runs (3-class N/S/V, DS2 test set):
  Run                                  Acc     Se_S    Se_V
  No class weights (paper as written)  95.56*  0.00    57.32
  Balanced weights, DS1-train only     90.98   35.01   86.71
  (* OvR accuracy)

Sensitivity experiments (1DCNN/1DCNN experiments/), aimed at the Se_S gap:
  Exp1 threshold calibration (tau=0.31)   Se_S 35 -> 57%   free, no retrain
  Exp2 ensemble + threshold               same as Exp1
  Exp3 S-beat augmentation x7             Se_S 18.7%       worse (OOD shift)
  Exp4 focal loss gamma=2                 Se_S 0.4%        fails at 160:1
  Exp5 full DS1 (944 vs 149 S beats)      Se_S 83%         best
  Conclusion: training data is the bottleneck, not the loss or tuning.

3. LightGBM re-run with normalised features (source/)
----------------------------------------------------
  - Retrained on features with per-record amplitude and RR
    normalisation. The old Optuna checkpoints were deleted first.
  - 100 Optuna trials per split, 5-fold CV.
      Random split:  13 Nov 19:21 -> 14 Nov 01:44
      DS1/DS2 split: 14 Nov 01:45 -> 14 Nov 05:54
  - Tuning gained only about +0.001 CV F1 over the paper's params.
  - Evaluated on 18 Nov. The log is in eval_step5_main.log on the
    GPU box.

  Metric       Random   DS1/DS2 new   DS1/DS2 before   Paper
  Accuracy     0.996    0.764         0.737            0.989
  Macro-F1     0.987    0.388         0.313            ~0.937
  Binary F1    0.992    0.409         0.342            0.928
  OVR AUC      0.999    0.787         0.769            0.985

  DS1/DS2 per-class F1: N 0.858, L 0.014, R 0.002, V 0.827 (was
  0.655), A 0.237 (was 0.067).

  Findings:
  - Normalisation helped V and A.
  - LBBB/RBBB are still about 0, because of patient-specific morphology.
  - CV F1 0.987 vs test 0.388: the beat-level CV folds mix beats from
    the same patients, so Optuna cannot tune for unseen patients.
