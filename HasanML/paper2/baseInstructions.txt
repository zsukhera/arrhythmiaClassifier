## IMPORTANT: how the paper's metrics appear to be computed (verify this)

The paper's numbers are consistent with MICRO-averaged one-vs-rest metrics,
not plain multiclass accuracy. Let e = multiclass error rate and K = 5:
  - "Sensitivity" = "F1" = micro-recall = plain multiclass accuracy = 1 - e
  - "Accuracy"    = mean one-vs-rest binary accuracy = 1 - 2e/K
  - "Specificity" = micro-specificity = 1 - e/(K-1)
Check: LR 20 features, e = 0.584 % -> 1 - 2(0.00584)/5 = 99.766 %,
1 - 0.00584/4 = 99.854 %. Both match the paper exactly. Same for 57 features
(e = 0.497 % -> 99.801 %, 99.876 %).
So the paper's true multiclass accuracy for LR is about 99.42 % (20 features)
and 99.50 % (57 features). Implement ALL of the following and report them
side by side: plain multiclass accuracy, OvR-averaged accuracy, micro / macro /
weighted sensitivity, specificity, precision, F1, per-class sensitivity and
PPV for N, S, V, F, Q, the full 5x5 confusion matrix, and the majority-class
("predict all N") baseline accuracy. Confirm or refute the micro-averaging
hypothesis in the README.

## Features (57 total, paper Table 2)

Implement fiducial-point detection inside fixed sub-windows of the 256-sample

(index 127), in ms, configurable:
  P wave:  R-250 to R-80   -> P peak, P onset (P1), P offset (P2)
  Q:       R-80  to R      -> Q point (local min before R), Q onset (Q1)
